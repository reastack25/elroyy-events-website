# Elroy Events

Premium event planning and equipment rental website built with Next.js, TypeScript, Tailwind CSS and a reusable component architecture.

## Phase 1

Phase 1 establishes the design system, global layout, responsive navigation, footer, homepage foundation, environment configuration and route placeholders.

## Local development

```bash
npm install
cp .env.example .env.local
npm run dev
```

Validation commands:

```bash
npm run typecheck
npm run lint
```

Company contact details and imagery are intentionally represented as replaceable placeholders until verified.
